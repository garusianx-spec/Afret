# دارایی‌های برند

| فایل | کاربرد |
| --- | --- |
| `mark.svg` | نماد مادر و کودک، با `fill="currentColor"` — قابل رنگ‌آمیزی |
| `mark-brand.svg` | همان نماد با رنگ ثابت برند `#AA4C7A` |
| `wordmark.svg` | لوگوتایپ فارسی «آفرت» |

## رنگ برند

`#AA4C7A` (بنفش-آلویی). توکن `--afrat-brand` در `globals.css` و کلاس
`text-brand` / `bg-brand` در Tailwind.

> این رنگ **عمداً** با اکسنت رابط کاربری (`#9C88FF` بنفش ملایم) یکی نیست.
> رنگ برند فقط برای لوگو است؛ دکمه‌ها و حالت‌های تعاملی همان بنفش ملایم
> و `#7A36D9` را نگه می‌دارند.

## تغییر لوگو

۱. `mark.svg` را با نسخهٔ جدید جایگزین کنید. باید:
   - یک `<path>` با `fill="currentColor"` داشته باشد،
   - `viewBox` داشته باشد و `width`/`height` ثابت نداشته باشد.
۲. آیکون‌ها را بازتولید کنید:

```bash
node apps/web/scripts/generate-icons.mjs
```

این دستور کل مجموعه را می‌سازد: آیکون‌های manifest، نسخه‌های maskable برای
اندروید، آیکون iOS، تصاویر splash برای TWA، فاوآیکون و `icons/icon.svg`.

۳. نسخهٔ React را هم به‌روزرسانی کنید. مسیر SVG داخل
`src/modules/auth/components/BrandMark.tsx` درون‌خطی شده تا از `currentColor`
ارث ببرد؛ مقدار `d` را از فایل جدید کپی کنید.

## اگر لوگو را به‌صورت PDF یا AI دریافت کردید

فایل را به SVG تبدیل کنید و مسیرها را به یک `<path>` واحد ساده کنید. نکتهٔ
مهم: بسیاری از خروجی‌های PDF هر قطعهٔ منحنی را یک زیرمسیر جدا می‌کنند و شکل
تکه‌تکه می‌شود؛ زیرمسیرها باید پیوسته باشند و فقط در شروع هر کانتور `M`
بگیرند.
