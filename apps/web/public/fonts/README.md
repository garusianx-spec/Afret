# فونت ایران‌یکان ایکس (IranYekan X VF)

فونت `IRANYekanX` تجاری است و در این مخزن قرار نمی‌گیرد (`.gitignore` فایل‌های
`*.woff2` این پوشه را نادیده می‌گیرد).

## نصب

۱. نسخهٔ variable فونت را از دارندهٔ لایسنس تهیه کنید.
۲. فایل را دقیقاً با این نام در همین پوشه قرار دهید:

```
apps/web/public/fonts/IRANYekanX-VF.woff2
```

۳. `@font-face` در `src/app/globals.css` به‌صورت خودکار آن را برمی‌دارد.

## پیش از نصب

تا وقتی فایل اضافه نشده، پشته به `Vazirmatn` و سپس فونت‌های فارسی سیستم
برمی‌گردد. متریک‌ها نزدیک‌اند، پس چیدمان به‌هم نمی‌ریزد.

> اگر لایسنس خرید فونت را ندارید، `Vazirmatn` (متن‌باز، SIL OFL) جایگزین
> مناسبی است: کافی است `Vazirmatn[wght].woff2` را اینجا بگذارید و نام
> خانوادهٔ فونت را در `globals.css` عوض کنید.
