# فونت برند — IranYekan Web

این پوشه **عمداً خالی است**. فونت ایران‌یکان تجاری است و در مخزن نگهداری
نمی‌شود (`.gitignore` فایل‌های `*.woff2` اینجا را نادیده می‌گیرد).

## نصب

سه فایل زیر را با همین نام‌ها در همین پوشه بگذارید:

```
apps/web/public/fonts/IRANYekanWeb-Regular.woff2    وزن ۴۰۰
apps/web/public/fonts/IRANYekanWeb-Medium.woff2     وزن ۵۰۰
apps/web/public/fonts/IRANYekanWeb-Bold.woff2       وزن ۷۰۰ (و ۶۰۰)
```

تمام. `@font-face` در `src/app/globals.css` خودش آن‌ها را برمی‌دارد و
`layout.tsx` برای Regular و Bold تگ `preload` می‌سازد. هیچ کد دیگری لازم
نیست تغییر کند.

## اگر فونت را نگذارید

اپ **بدون خطا** build و اجرا می‌شود و پشتهٔ فونت به `Vazirmatn` و سپس
فونت‌های فارسی سیستم برمی‌گردد. متریک‌ها نزدیک‌اند، پس چیدمان به‌هم
نمی‌ریزد — فقط ظاهر حروف فرق می‌کند.

این رفتار عمدی است و دلیل انتخاب `@font-face` به‌جای `next/font/local` هم
همین بود: `next/font` مسیر فایل را در زمان build حل می‌کند، پس نبودن فونت
build را **می‌شکست** و هر clone تازه از کار می‌افتاد.

هزینه‌اش این است که Next خودش preload و fingerprint نمی‌سازد. جبران شده:

- `layout.tsx` تگ `preload` را دستی می‌سازد، اما **فقط اگر فایل روی دیسک
  باشد** — وگرنه هر بارگذاری صفحه یک ۴۰۴ و هشدار «preload بلااستفاده» می‌داد.
- `next.config.mjs` هدر `Cache-Control: public, max-age=31536000, immutable`
  روی `/fonts/*` می‌گذارد.
- سرویس‌ورکر این مسیر را با استراتژی cache-first نگه می‌دارد.

## جایگزین متن‌باز

اگر لایسنس ایران‌یکان را ندارید، **Vazirmatn** (متن‌باز، SIL OFL) جایگزین
خوبی است. فایل‌ها را با همین سه نام اینجا بگذارید یا نام خانوادگی فونت را در
`globals.css` عوض کنید.

## اضافه کردن وزن دیگر

یک بلوک `@font-face` در `src/app/globals.css` اضافه کنید. اگر وزنی را
تعریف نکنید، مرورگر از نزدیک‌ترین وزن موجود **بولد مصنوعی** می‌سازد که در
فارسی زشت است — به همین دلیل وزن ۶۰۰ عمداً به فایل Bold نگاشت شده.
