# فایل‌های صوتی

پخش‌کنندهٔ «صداهای آرام‌بخش» (`SoundPlayer`) فایل‌های زیر را از همین پوشه
می‌خواند. هیچ‌کدام در مخزن نیستند تا حجم مخزن بالا نرود.

| فایل | توضیح |
| --- | --- |
| `white-noise.mp3` | نویز سفید ملایم |
| `pink-noise.mp3` | نویز صورتی |
| `heartbeat.mp3` | ضربان قلب مادر |
| `rain.mp3` | صدای باران |
| `waves.mp3` | موج دریا |
| `lullaby-lori.mp3` | لالایی لری |
| `lullaby-classic.mp3` | لالایی کلاسیک |

نکته‌ها:

- فایل‌ها باید **loop-safe** باشند (بدون سکوت در ابتدا و انتها) چون پخش با
  `audio.loop = true` انجام می‌شود.
- حجم هر فایل را زیر ۲ مگابایت نگه دارید؛ سرویس‌ورکر آن‌ها را با استراتژی
  cache-first و سقف حجمی نگه می‌دارد.
- فقط از منابعی استفاده کنید که اجازهٔ انتشار تجاری دارند.
