# اسکرین‌شات‌های manifest

`manifest.webmanifest` به دو اسکرین‌شات ارجاع می‌دهد که کارت نصب PWA در کروم
اندروید از آن‌ها استفاده می‌کند:

| فایل | ابعاد | محتوا |
| --- | --- | --- |
| `home-narrow.png` | 1080×1920 | داشبورد امروز |
| `chat-narrow.png` | 1080×1920 | گفتگو با پزشک |

بدون این‌ها کارت نصب ساده‌تر (بدون پیش‌نمایش) نمایش داده می‌شود؛ خطایی رخ
نمی‌دهد.

## تولید

```bash
npm run build --workspace=apps/web
npx next start -p 3000 --dir apps/web
```

سپس با هر ابزار اسکرین‌شاتی در ویوپورت 1080×1920 (یا 360×640 با
`deviceScaleFactor: 3`) عکس بگیرید و اینجا بگذارید.
