# سیستم طراحی آفرت

## توکن‌های رنگ

همهٔ رنگ‌ها به‌صورت سه‌تایی کانال در `:root` تعریف شده‌اند
(`apps/web/src/app/globals.css`) تا Tailwind بتواند `<alpha-value>` را اعمال
کند و همان مقدار از CSS خام، متا تگ `theme-color` و پوستهٔ آفلاین هم خوانده
شود — بدون تکرار هیچ hex.

| نقش | توکن | مقدار |
| --- | --- | --- |
| اکسنت اصلی | `primary` | `#9C88FF` |
| CTA / تأکید عمیق | `primary-deep` | `#7A36D9` |
| پس‌زمینه | `surface` | `#F8F7FC` |
| سطح کارت | `surface-card` | `#FFFFFF` |
| حاشیهٔ کارت | `surface-border` | `#F1EBFA` |
| هشدار / بارداری | `coral` | `#FFAAA6` |
| موفقیت / چک‌لیست | `mint` | `#48BB78` |
| تیتر | `ink` | `#2D2B3F` |
| متن بدنه | `ink-muted` | `#6B687E` |

استفاده: `bg-primary`, `text-primary-deep`, `border-surface-border`,
`bg-primary/15` (شفافیت کار می‌کند چون توکن‌ها کانالی‌اند).

## تایپوگرافی

فونت **IranYekan X VF** تجاری است و در مخزن نیست. فایل را در
`apps/web/public/fonts/IRANYekanX-VF.woff2` بگذارید؛ `@font-face` خودش آن را
برمی‌دارد. تا آن زمان پشته به `Vazirmatn` و فونت‌های فارسی سیستم برمی‌گردد.

### ارقام فارسی

هیچ عددی مستقیم رندر نمی‌شود. همه از `src/lib/persian.ts` عبور می‌کنند:

```ts
toFaDigits(22)                    // '۲۲'
formatFa(1840)                    // '۱٬۸۴۰'
formatFaUnit(68.5, 'کیلوگرم')     // '۶۸٫۵ کیلوگرم'
formatFaTime(Date.now())          // '۱۹:۴۰'
formatGestational(22, 3)          // '۲۲ هفته و ۳ روز'
```

برای ورودی فرم‌ها `toEnDigits()` مسیر برگشت است — کاربر ممکن است با صفحه‌کلید
فارسی «۶۸٫۵» تایپ کند و `Number()` آن را نمی‌فهمد.

### تاریخ شمسی

`src/lib/jalali.ts` روی `date-fns-jalali` نشسته است. نکتهٔ مهم: گروه‌بندی
پیام‌ها بر مرز روز **شمسی** انجام می‌شود، نه UTC — وگرنه جداکنندهٔ «امروز» در
ساعات شب جابه‌جا می‌شود.

## RTL

`<html lang="fa-IR" dir="rtl">` و بعد هیچ استایل آینه‌ای دستی لازم نیست، به
شرطی که از ابزارهای منطقی Tailwind استفاده شود:

| به‌جای | بنویسید |
| --- | --- |
| `pl-*` / `pr-*` | `ps-*` / `pe-*` |
| `ml-*` / `mr-*` | `ms-*` / `me-*` |
| `left-*` / `right-*` | `start-*` / `end-*` |
| `border-l` / `border-r` | `border-s` / `border-e` |
| `rounded-bl` | `rounded-es` |

### دام‌هایی که خودکار حل نمی‌شوند

- **آیکون‌های جهت‌دار.** فلش «ارسال» باید به inline-end اشاره کند؛ با
  `-scale-x-100` برگردانده شده. «بازگشت» در RTL یعنی `ChevronRight`، نه `Left`.
- **حلقهٔ پیشرفت.** SVG با `rotate(-90deg) scaleX(-1)` چرخانده شده تا پیشرفت
  در جهتی که خوانندهٔ فارسی انتظار دارد پیش برود.
- **ترتیب تب‌ها.** ترتیب منبع در `BottomNav` همان ترتیب بصری راست‌به‌چپ است؛
  «خانه» سمت راست می‌نشیند، جایی که شست کاربر شروع می‌کند.
- **متن مختلط.** `dir="auto"` روی textarea کامپوزر تا پیام انگلیسی درست
  تراز شود.

## چیدمان

- **mobile-first**، حداکثر عرض محتوا `max-w-lg`.
- نوار تب پایین ثابت است؛ `.afrat-page` ارتفاعش را به‌علاوهٔ safe-area رزرو
  می‌کند تا آخرین کارت زیر نوار نرود.
- `viewport-fit=cover` در `layout.tsx` + کلاس‌های `afrat-safe-top` /
  `afrat-safe-bottom` برای notch و نوار ژست اندروید.
- حداقل هدف لمسی: کلاس `.afrat-tap` (۴۴×۴۴ پیکسل) روی هر عنصر تعاملی.

## دسترس‌پذیری

- zoom غیرفعال **نشده** (`maximumScale: 5`) — غیرفعال کردنش WCAG 1.4.4 را نقض
  می‌کند.
- هر آیکون تزئینی `aria-hidden="true"` دارد و برچسب متنی کنارش.
- تیک‌های تحویل نام دسترس‌پذیر فارسی دارند («دیده شد»، «ارسال نشد»).
- لاگ گفتگو `role="log"` + `aria-live="polite"` است.
- «در حال نوشتن…» `role="status"` است تا ادب اسکرین‌ریدر حفظ شود.
- `prefers-reduced-motion` همهٔ انیمیشن‌ها را خاموش می‌کند.
- حالت فوکوس: حلقهٔ `ring-2 ring-primary-deep` روی همه‌چیز.
